# PlayerNation Ratings Engine

A ratings system that turns raw Wyscout match-event data into a **Football
Identity Card** for every player and coach: an Overall, five explainable
attributes, an archetype, a confidence level, and plain-English reasoning.

Built on the full dataset — **7 competitions, 1,941 matches, 3.25M events,
2,803 rated players, 211 coaches.**

> Methodology and design rationale: see `../METHODOLOGY.md` and
> `../RATING_DECISIONS.md`.

---

## Quick start

```bash
# 1. set up (Python 3.11+)
python -m venv .venv && source .venv/bin/activate
pip install pandas numpy pyarrow            # to rebuild ratings
pip install jupyter jupytext matplotlib     # only if you want to run the notebooks

# 2. rebuild everything from raw_data/ (~30 seconds)
python process.py                            # writes ratings.json

# 3. view the web app
python -m http.server 8000
#    open http://localhost:8000
```

`ratings.json` is already included, so you can skip step 2 and go straight to
the web app if you just want to explore.

## What's here

| File | What it is |
|---|---|
| **`wyscout_lib.py`** | The engine. All logic: loaders, event enrichment, aggregation, attributes, confidence, archetypes, coaches, export. The notebooks and `process.py` are thin callers of this. |
| **`process.py`** | One command to rebuild the whole pipeline and write `ratings.json`. |
| **`index.html`** | The web app — searchable player cards + coach tactical profiles. Self-contained, no external libraries. |
| **`ratings.json`** | Generated output the web app reads (players + coaches). |
| **`01`–`06_*.ipynb`** | The pipeline as a guided notebook walkthrough, one phase each (below). |
| `data/` | Cached intermediate tables (parquet). Regenerated by `process.py`; gitignored. |

### The notebooks (run in order)

| Notebook | Phase | Output |
|---|---|---|
| `00_eda` | **Reproducible data audit** — proves every Phase-0 decision live from the raw files (goal-source, tag meanings, coordinate system, encoding traps) | (evidence) |
| `01_master_tables` | Load + clean; **minutes played**; enrich all 3.25M events | master tables |
| `02_player_match_stats` | One row per player per match — the atomic table | `player_match_stats` |
| `03_player_career_stats` | Aggregate to per-90s + accuracy rates (no ratings yet) | `player_career_stats` |
| `04_feature_sanity` | The football common-sense gate — top-25 leaderboards | (review) |
| `05_attributes_ratings` | Percentiles → attributes → Bayesian confidence → archetypes | `player_ratings` |
| `06_coach_ratings` | Results Overall + 6-dim tactical profiles per coach | `coach_ratings` |

Start with `00_eda` — it's the from-scratch audit that justifies every data
decision the rest of the pipeline relies on (nothing is taken on faith).

The notebooks were authored with [jupytext](https://jupytext.readthedocs.io);
each carries its executed outputs so you can read them without running anything.

## Using the app

- **Players tab** — search by name/nationality, filter by position and
  confidence, sort by Overall or any attribute. Click a card for the full
  identity card: attribute bars with explanations, strengths/areas, season
  stats, and a shareable summary.
- **Coaches tab** — a FIFA-style **Overall** (results-based) + confidence stars,
  plus a 6-dimension tactical profile (Attacking Intent · Possession · Pressing ·
  Defensive Solidity · **Width** · **Line Height**), a style archetype, and
  per-dimension explanations for managers with enough games; Overall + record
  only otherwise. Coaches are labelled by team + competition (names aren't in
  the dataset).

## Validation built in

`process.py` asserts the non-negotiables on every run: minutes ∈ [0, 120],
and authoritative vs event-derived goals agree to < 1 %. The feature gate
(notebook 04) confirms the right players top each leaderboard before any rating
is trusted.
